# Images

Drop photos of your models here, then reference the filename in `data/inventory.json`.

A unit can have one photo or several:
```json
"images": ["images/intercessors-front.jpg", "images/intercessors-back.jpg"]
```

Keep filenames simple, lowercase, no spaces. Resize big phone photos down before adding them
(aim under ~500KB) — try https://squoosh.app if you need an easy resizer.
